## 📝 Key Business Rules Documented

### Resource Module
✅ DA resources MUST have Team Lead  
✅ WD resources can be "Unassigned"  
✅ Subcontractors have different field structure  
✅ EIN uniqueness enforced  
✅ Event-specific resource copying  
✅ Email/phone normalization patterns  

### User Access Management
✅ Always use `cleanEmail()` for emails  
✅ Never use `prisma.user.delete()` directly  
✅ Multi-tenant patterns  
✅ Permission system (module-action model)  
✅ Category-based access control
